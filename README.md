# Patrick's Claude Code Plugins

Personal Claude Code plugin marketplace.

## Installation

```
/plugin marketplace add phuston/cc-plugins
```

## Plugins

### pm

Personal task management skills for Obsidian daily/weekly notes.

```
/plugin install pm@phuston-plugins
```

**Skills:**
- `pm:day-start` — morning planning with task carry-over
- `pm:day-end` — end-of-day review, activity log, reflections
- `pm:week-start` — weekly intentions and Monday task seeding
- `pm:week-end` — weekly review, git summary, performance narrative
- `pm:check-in` — quick mid-day status check
